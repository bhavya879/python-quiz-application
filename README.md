# Python Quiz Application

## 1. Project Overview

**Python Quiz Application** is a console-based quiz management system
developed using Python. It allows students to log in, read quiz
instructions, answer multiple-choice questions, view their results, and
save their scores. An administrator can log in separately and export the
stored quiz results to an Excel file.

The application is divided into separate Python modules so that the quiz
questions, student functions, administrator functions, and main program
are easier to manage.

------------------------------------------------------------------------

## 2. Objectives

The main objectives of this project are:

-   To create a simple and user-friendly online quiz application.
-   To provide separate login options for students and administrators.
-   To display multiple-choice questions with four options.
-   To validate student answers.
-   To calculate the student's score and percentage.
-   To assign a grade based on the percentage.
-   To save student results in a CSV file.
-   To allow the administrator to export results to an Excel file.
-   To demonstrate Python concepts such as functions, lists,
    dictionaries, loops, conditions, modules, file handling, and
    libraries.

------------------------------------------------------------------------

## 3. Features

### Student Features

-   Student name and roll number entry.
-   Student menu.
-   Quiz instructions.
-   15 multiple-choice questions.
-   Four options for each question.
-   Input validation for answers.
-   Questions are shuffled before the quiz.
-   One mark for each correct answer.
-   No negative marking.
-   Immediate indication of correct/incorrect answers.
-   Automatic score calculation.
-   Percentage calculation.
-   Grade assignment.
-   Result display.
-   Result storage in `quizresults.csv`.

### Admin Features

-   Admin login.
-   Admin menu.
-   Reading stored quiz results.
-   Exporting results to an Excel file.
-   Choosing the folder where the Excel result file should be saved.
-   Error handling when the result CSV file is unavailable.

### `main.py`

This is the main entry point of the application.

It:

-   Imports functions from the other modules.
-   Displays the main menu.
-   Provides Admin Login, Student Login, and Exit options.
-   Calls the appropriate function based on the user's choice.
-   Keeps the application running using a `while` loop until the user
    chooses Exit.

### `questions.py`

This module contains the quiz questions.

The questions are stored as dictionaries inside a list. Each question
contains:

-   `question`
-   `options`
-   `answer`

The `return_questions()` function returns the complete list of
questions.

### `quiz.py`

This module contains the main quiz-related functions.

Important functions include:

-   `show_instructions()`
-   `calculate_percentage()`
-   `ask_question()`
-   `assign_grade()`
-   `show_result()`
-   `start_quiz()`

It handles displaying questions, accepting answers, calculating scores,
assigning grades, and displaying results.

### `students.py`

This module handles student-related operations.

Important functions include:

-   `student_login()`
-   `student_menu()`
-   `student_session()`
-   `save_result()`

It collects student details, starts the quiz session, and saves the
student's result.

### `admin.py`

This module handles administrator operations.

Important functions include:

-   `admin_menu()`
-   `print_results()`

The administrator can read `quizresults.csv` using Pandas and export the
results to `QuizResults.xlsx`.

### `quizresults.csv`

This file stores the results of completed quizzes.

The stored information includes:

-   Roll Number
-   Student Name
-   Score
-   Total Questions
-   Percentage
-   Grade

### `QuizResults.xlsx`

This Excel file is generated by the administrator when the results are
exported.

## 7. Installation and Requirements

### Step 1: Install Python

Install Python 3 on the computer.

Check whether Python is installed:

``` bash
python --version
```

### Step 2: Install Pandas

Run:

``` bash
pip install pandas
```

The Excel export also requires an Excel-writing engine. If needed,
install:

``` bash
pip install openpyxl
```

### Step 3: Keep the Files in One Folder

Place the following files in the same project folder:

``` text
main.py
quiz.py
questions.py
students.py
admin.py
```

The `quizresults.csv` file will be used to store results.

------------------------------------------------------------------------

## 8. How to Run the Application

Open a terminal in the project folder and run:

``` bash
python main.py
```

The main menu will appear:

``` text
========================================
        PYTHON QUIZ APPLICATION
========================================
1. Admin Login
2. Student Login
3. Exit
```

Enter the required choice and follow the instructions displayed by the
application.
